# Design Thinking

Phương pháp thiết kế lấy con người làm trung tâm.

## 5 Stages

### 1. Empathize

Hiểu users và needs của họ

-   User interviews
-   Observations
-   Empathy maps

### 2. Define

Xác định problem statement

-   Point of view statement: "[User] needs [need] because [insight]"
-   "How might we..." questions

### 3. Ideate

Brainstorm solutions

-   Many ideas, no judgment
-   Crazy ideas welcome
-   Build on others' ideas

### 4. Prototype

Tạo low-fidelity prototypes

-   Paper sketches
-   Wireframes
-   Click through prototypes

### 5. Test

Test với real users

-   Get feedback
-   Iterate based on findings
-   Repeat process

## User Persona

```markdown
## Persona: Tech-Savvy Professional

**Age:** 28-35
**Occupation:** Software Engineer
**Goals:**

-   Learn new technologies quickly
-   Find practical code examples
-   Stay updated with best practices

**Pain Points:**

-   Too much theory, not enough practice
-   Outdated documentation
-   Complex explanations

**Tech Comfort:** High
```

## User Journey Map

```
Awareness → Consideration → Purchase → Retention → Advocacy

- What user thinks
- What user does
- Pain points
- Opportunities
```

## Design Principles

1. **User-centered** - Focus on user needs
2. **Iterative** - Design, test, improve, repeat
3. **Collaborative** - Involve stakeholders
4. **Empathetic** - Understand user emotions
5. **Prototype early** - Fail fast, learn quick
