## Quick Comparison

| Property | Primitive | Non-primitive (Object) |
| -------- | --------- | ---------------------- |
| **Mutable?** | ❌ Immutable | ✅ Mutable |
| **Comparison** | By value | By reference |
| **Copy** | Copies value | Copies reference |
| **typeof** | Returns type name | `"object"` or `"function"` |

<Aside type="tip" title="Remember">
- **7 Primitive types**: `number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `symbol`
- **Non-primitive**: Everything else — Objects, Arrays, Functions, Date, Map, Set, …
</Aside>
