## What is a Prototype?

Every object in JavaScript has a hidden **prototype** object that it inherits from. When you access a property or method on an object, JavaScript:

1. Looks for it in the object itself
2. If not found → looks in the object's **prototype**
3. Continues up the **prototype chain** until found or reaches `null`

<Aside type="note" title="__proto__">
Every object has a special `__proto__` property pointing to its prototype. You can access it via `Object.getPrototypeOf(obj)`.
</Aside>

---

## Prototype of an Object

```js
function Person(name) {
    this.name = name;
}

// Add method to prototype
Person.prototype.sayHello = function() {
    console.log(`Hello, I'm ${this.name}`);
};

let john = new Person("John");
john.sayHello(); // "Hello, I'm John"

// john doesn't have sayHello directly
console.log(john.hasOwnProperty("sayHello")); // false
```

  <Card title="Look in Prototype" icon="right-arrow">

## Prototype Chain (Prototypal Inheritance)

**Prototypal inheritance** allows objects to inherit properties and methods from other objects through the prototype chain. Instead of recreating methods in each object, you create them once in the prototype and all inheriting objects can use them.

### Example: Inheriting from Animal

<Tabs>
  <TabItem label="Constructor Functions">
    ```js
    function Animal(name) {
        this.name = name;
    }

    Animal.prototype.speak = function() {
        console.log(`${this.name} makes a sound`);
    };

    function Dog(name, breed) {
        Animal.call(this, name);
        this.breed = breed;
    }

    // Inherit from Animal
    Dog.prototype = Object.create(Animal.prototype);
    Dog.prototype.constructor = Dog;

    Dog.prototype.bark = function() {
        console.log(`${this.name} barks!`);
    };

    let dog = new Dog("Buddy", "Golden Retriever");
    dog.speak(); // "Buddy makes a sound" (inherited)
    dog.bark();  // "Buddy barks!" (own method)
    ```
  </TabItem>
  <TabItem label="ES6 Classes">
    ```js
    class Animal {
        constructor(name) {
            this.name = name;
        }
        speak() {
            console.log(`${this.name} makes a sound`);
        }
    }

    class Dog extends Animal {
        constructor(name, breed) {
            super(name);
            this.breed = breed;
        }
        bark() {
            console.log(`${this.name} barks!`);
        }
    }

    let dog = new Dog("Buddy", "Golden Retriever");
    dog.speak(); // "Buddy makes a sound"
    dog.bark();  // "Buddy barks!"
    ```

    <Aside type="tip" title="Modern Alternative">
    ES6 `class` syntax is **syntactic sugar** over prototypes — much easier to read and write, but the underlying mechanism is the same.
    </Aside>
  </TabItem>
</Tabs>

## The Prototype Chain Visualized

When accessing `dog.speak()`:

```
dog → Dog.prototype → Animal.prototype → Object.prototype → null
```

<CardGrid>
  <Card title="Step 1" icon="magnifier">
    Look for `speak` in `dog` → not found
  </Card>
  <Card title="Step 2" icon="right-arrow">
    Look in `Dog.prototype` → not found
  </Card>
  <Card title="Step 3" icon="approve-check">
    Look in `Animal.prototype` → **found!**
  </Card>
</CardGrid>

<Aside type="caution" title="Important Notes">
- If the entire chain is traversed without finding → returns `undefined`
- The chain always ends at `Object.prototype` → `null`
- Never modify `Object.prototype` as it affects all objects
</Aside>
