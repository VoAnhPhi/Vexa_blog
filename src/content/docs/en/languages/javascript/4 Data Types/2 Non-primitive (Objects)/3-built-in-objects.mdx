## What are Built-in Objects?

Built-in objects (also called **global objects**) are objects provided by the JavaScript language itself. They are available **everywhere** in your code without importing or requiring them.

<Aside type="note" title="Definition">
Built-in objects are predefined by the language to help developers handle common data types and operations.
</Aside>

---

## Common Built-in Objects

| Object | Purpose | Common Methods/Properties |
| ------ | ------- | ------------------------- |
| **Number** | Work with numbers | `toFixed()`, `toPrecision()`, `isNaN()`, `isFinite()` |
| **Math** | Mathematical operations | `Math.PI`, `Math.sqrt()`, `Math.pow()`, `Math.floor()`, `Math.ceil()`, `Math.round()`, `Math.random()` |
| **Date** | Work with dates/times | `getFullYear()`, `getMonth()`, `getDate()`, `toISOString()`, `toLocaleString()` |
| **String** | String manipulation | `length`, `toUpperCase()`, `toLowerCase()`, `trim()`, `includes()`, `split()`, `replace()` |
| **Boolean** | Logic values | `valueOf()`, `toString()` |
| **Function** | Functions | `call()`, `apply()`, `bind()`, `length`, `name` |
| **Error** | Error handling | `message`, `name`, `stack` |
| **Array** | Array operations | `push()`, `pop()`, `map()`, `filter()`, `reduce()`, `find()`, `includes()`, `sort()` |
| **Object** | Object utilities | `keys()`, `values()`, `entries()`, `assign()`, `freeze()` |
| **Map** | Key-value collections | `set()`, `get()`, `has()`, `delete()`, `clear()`, `size` |
| **Set** | Unique value collections | `add()`, `delete()`, `has()`, `clear()`, `size` |
| **RegExp** | Regular expressions | `test()`, `exec()`, `match()`, `replace()` |
| **Promise** | Async operations | `then()`, `catch()`, `finally()`, `Promise.all()` |

## Examples

<Tabs>
  <TabItem label="Math">
    ```js
    Math.PI;           // 3.141592653589793
    Math.sqrt(16);     // 4
    Math.floor(4.7);   // 4
    Math.ceil(4.2);    // 5
    Math.round(4.5);   // 5
    Math.random();     // Random number between 0 and 1
    Math.abs(-5);      // 5
    Math.pow(2, 3);    // 8
    ```
  </TabItem>
  <TabItem label="Array">
    ```js
    let arr = [1, 2, 3, 4, 5];

    arr.map(x => x * 2);         // [2, 4, 6, 8, 10]
    arr.filter(x => x > 2);      // [3, 4, 5]
    arr.reduce((a, b) => a + b); // 15
    arr.find(x => x === 3);      // 3
    arr.includes(4);              // true
    ```
  </TabItem>
  <TabItem label="Set & Map">
    ```js
    // Set — unique values only
    let set = new Set([1, 2, 2, 3, 3, 3]);
    console.log(set);   // Set { 1, 2, 3 }
    set.has(2);          // true
    set.size;            // 3

    // Map — keys can be any type
    let map = new Map();
    map.set("name", "Alice");
    map.set(42, "answer");
    map.get("name");     // "Alice"
    ```
  </TabItem>
  <TabItem label="Date">
    ```js
    let now = new Date();
    now.getFullYear();     // 2026
    now.getMonth();        // 0-11 (January = 0)
    now.getDate();         // 1-31
    now.toDateString();    // "Mon Feb 09 2026"
    now.toISOString();     // ISO format string
    ```
  </TabItem>
</Tabs>

## Key Takeaways

<Aside type="note" title="Always Available">
- Built-in objects are part of the **global scope** — use them anywhere without imports
- Some additional built-in objects: `RegExp`, `Promise`, `Error`, `Proxy`, `Reflect`
- Modern JavaScript keeps adding new built-in objects and methods with each ECMAScript release
</Aside>
