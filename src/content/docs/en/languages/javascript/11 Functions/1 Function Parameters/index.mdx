## Parameters vs Arguments

- **Parameters:** "placeholders" in the function declaration — variable names **representing the expected inputs**.
- **Arguments:** the **actual values** you pass when calling the function.

```js
function add(a, b) {          // a, b are parameters
  return a + b;
}
add(2, 3);                    // 2, 3 are arguments
```

---

### `fn.length`

`fn.length` returns the **number of expected positional parameters** — counting up to the **first default parameter**, excluding `...rest`:

```js
function f(a, b, c) {}        // f.length === 3
function g(a, b = 1, c) {}    // g.length === 1 (stops at b which has default)
function h(a, ...rest) {}     // h.length === 1
```

---

### Mismatched Argument Count

<Tabs>
  <TabItem label="Too few arguments">
    Parameters that don't receive a value become `undefined`:

    ```js
    function greet(name, greeting) {
      console.log(greeting, name);
    }
    greet("An");       // undefined "An"
    ```
  </TabItem>
  <TabItem label="Too many arguments">
    Extra arguments are **ignored** (unless using `arguments` or `...rest`):

    ```js
    function add(a, b) {
      return a + b;
    }
    add(1, 2, 3, 4);  // 3 (only uses first 2 arguments)
    ```
  </TabItem>
  <TabItem label="arguments object">
    The `arguments` object contains **all** arguments (only in non-arrow functions):

    ```js
    function showAll() {
      console.log(arguments);        // [Arguments] { '0': 1, '1': 2, '2': 3 }
      console.log(arguments.length); // 3
    }
    showAll(1, 2, 3);
    ```

    <Aside type="caution" title="Note">
    `arguments` is **array-like**, not a real Array — it doesn't have `.map()`, `.filter()`.
    Use `Array.from(arguments)` or `[...arguments]` to convert, or use **rest parameters** instead.
    </Aside>
  </TabItem>
</Tabs>

## Default Parameters

Automatically use a **default value** when the argument is `undefined`. Default values are **evaluated at call time**, from **left → right**.

### Syntax

```js
function fn(param = defaultValue) { ... }
```

### Examples

<Tabs>
  <TabItem label="Basic">
    ```js
    function greet(name = 'friend') {
      return `Hi, ${name}!`;
    }

    greet();            // "Hi, friend!"   (no arg → undefined → uses default)
    greet(undefined);   // "Hi, friend!"   (undefined → uses default)
    greet(null);        // "Hi, null!"     (null ≠ undefined → does NOT use default)
    greet('');          // "Hi, !"         ('' ≠ undefined → does NOT use default)
    ```
  </TabItem>
  <TabItem label="Reference earlier params">
    Later parameters can **reference earlier ones**:

    ```js
    function createUser(name, role = 'user', greeting = `Welcome, ${name}!`) {
      return { name, role, greeting };
    }

    createUser('An');
    // { name: 'An', role: 'user', greeting: 'Welcome, An!' }
    ```
  </TabItem>
  <TabItem label="Complex expressions">
    Defaults can be **any expression** — evaluated on each call:

    ```js
    function log(msg, time = Date.now()) {
      console.log(`[${time}] ${msg}`);
    }

    log("start"); // [1709474400000] start
    // each call → new Date.now()
    ```
  </TabItem>
</Tabs>

<Aside type="tip" title="Compared to the old way">
```js
// ❌ Old way (ES5) — fails with valid falsy values (0, "", false)
function old(x) {
  x = x || 10;  // 0 also gets replaced with 10!
}

// ✅ Default parameter — only when undefined
function modern(x = 10) {
  // x = 0 → stays 0
}
```
</Aside>

## Rest Parameters

Use `...name` at the **end** of the parameter list to **gather all remaining arguments into a real Array**.

### Syntax

```js
function fn(first, second, ...rest) { ... }
```

### Examples

<Tabs>
  <TabItem label="Gather all">
    ```js
    function sum(...nums) {
      return nums.reduce((s, n) => s + n, 0);
    }

    sum(1, 2, 3);    // 6
    sum(10, 20);     // 30
    sum();           // 0
    ```
  </TabItem>
  <TabItem label="Gather remaining">
    ```js
    function tagLog(tag, ...items) {
      console.log(tag, items);
    }

    tagLog('DEBUG', 'a', 1, { x: 3 });
    // 'DEBUG' ['a', 1, { x: 3 }]
    // → tag = 'DEBUG', items = ['a', 1, { x: 3 }]
    ```
  </TabItem>
  <TabItem label="Replace arguments">
    ```js
    // ❌ Old: using arguments (array-like, not in arrow functions)
    function old() {
      return Array.from(arguments).join(', ');
    }

    // ✅ New: rest parameters (real array, works in arrow functions)
    const modern = (...args) => args.join(', ');

    old(1, 2, 3);     // "1, 2, 3"
    modern(1, 2, 3);   // "1, 2, 3"
    ```
  </TabItem>
</Tabs>

---

### Rest vs Spread

<Aside type="caution" title="Don't confuse them!">
Same `...` syntax but **different contexts**:

| Context | Name | Behavior | Example |
| ------- | ---- | -------- | ------- |
| Function **declaration** | **Rest** | Gather many args → **1 array** | `function f(...args) {}` |
| Function **call** | **Spread** | Spread 1 array → **many args** | `f(...arr)` |
</Aside>

<Tabs>
  <TabItem label="Rest (declaration)">
    ```js
    // ...nums GATHERS the arguments into an array
    function sum(...nums) {
      return nums.reduce((s, n) => s + n, 0);
    }
    ```
  </TabItem>
  <TabItem label="Spread (call)">
    ```js
    const arr = [1, 2, 3];
    // ...arr SPREADS the array into individual arguments
    sum(...arr); // equivalent to sum(1, 2, 3) → 6
    ```
  </TabItem>
</Tabs>

## Rules & Best Practices

<CardGrid>
  <Card title="Rest must be last" icon="warning">
    `...rest` must be the **last parameter**:

    ```js
    // ✅
    function ok(a, b, ...rest) {}

    // ❌ SyntaxError
    function bad(...rest, last) {}
    ```
  </Card>
  <Card title="Only one rest per function" icon="close">
    You cannot have 2 rest parameters:

    ```js
    // ❌ SyntaxError
    function bad(...a, ...b) {}
    ```
  </Card>
  <Card title="Default before rest" icon="approve-check">
    Recommended order: required → default → rest:

    ```js
    function api(url, method = 'GET', ...headers) {
      // url: required
      // method: has default
      // headers: gathers the rest
    }
    ```
  </Card>
  <Card title="Destructuring in params" icon="setting">
    Combine destructuring for a clearer API:

    ```js
    function createUser({ name, age = 18, role = 'user' } = {}) {
      return { name, age, role };
    }

    createUser({ name: 'An' });
    // { name: 'An', age: 18, role: 'user' }
    ```
  </Card>
</CardGrid>

## Summary

| Concept | Description | Remember |
| ------- | ----------- | -------- |
| **Parameters** | Variables in function declaration | `fn.length` counts up to first default |
| **Arguments** | Values when calling | Extra → ignored, missing → `undefined` |
| **Default** | `param = value` | Only triggers on `undefined`, NOT `null` |
| **Rest** | `...rest` | Gathers into a real array, must be last |
| **Spread** | `...arr` (in call) | Spreads array into individual arguments |
