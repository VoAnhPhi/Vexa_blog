## Parameters vs Arguments

- **Parameters:** "placeholders" in the function declaration — variable names **representing the expected inputs**.
- **Arguments:** the **actual values** you pass when calling the function.

```js
function add(a, b) {          // a, b are parameters
  return a + b;
}
add(2, 3);                    // 2, 3 are arguments
```

---

### `fn.length`

`fn.length` returns the **number of expected positional parameters** — counting up to the **first default parameter**, excluding `...rest`:

```js
function f(a, b, c) {}        // f.length === 3
function g(a, b = 1, c) {}    // g.length === 1 (stops at b which has default)
function h(a, ...rest) {}     // h.length === 1
```

---

### Mismatched Argument Count

<Tabs>
  <TabItem label="Too few arguments">
    Parameters that don't receive a value become `undefined`:

    ```js
    function greet(name, greeting) {
      console.log(greeting, name);
    }
    greet("An");       // undefined "An"
    ```
  </TabItem>
  <TabItem label="Too many arguments">
    Extra arguments are **ignored** (unless using `arguments` or `...rest`):

    ```js
    function add(a, b) {
      return a + b;
    }
    add(1, 2, 3, 4);  // 3 (only uses first 2 arguments)
    ```
  </TabItem>
  <TabItem label="arguments object">
    The `arguments` object contains **all** arguments (only in non-arrow functions):

    ```js
    function showAll() {
      console.log(arguments);        // [Arguments] { '0': 1, '1': 2, '2': 3 }
      console.log(arguments.length); // 3
    }
    showAll(1, 2, 3);
    ```

    <Aside type="caution" title="Note">
    `arguments` is **array-like**, not a real Array — it doesn't have `.map()`, `.filter()`.
    Use `Array.from(arguments)` or `[...arguments]` to convert, or use **rest parameters** instead.
    </Aside>
  </TabItem>
</Tabs>

## Summary

| Concept | Description | Remember |
| ------- | ----------- | -------- |
| **Parameters** | Variables in function declaration | `fn.length` counts up to first default |
| **Arguments** | Values when calling | Extra → ignored, missing → `undefined` |
| **`arguments`** | Array-like object with all arguments | Only in non-arrow functions |
