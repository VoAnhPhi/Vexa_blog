JavaScript has two main categories of data types: **Primitive types** and **Non-primitive types** (Objects).

## Primitive Types

Primitive types are the most basic data types in JavaScript. They are **immutable** (cannot be changed) and are compared by value.

<Aside type="note" title="Key Properties">
- **Immutable** - Values cannot be changed
- **Compared by value** - Two variables with the same value are equal
- **Copied by value** - Assignments copy the value, not a reference
</Aside>

### Detail by Type

<Tabs>
  <TabItem label="number">
    Includes integers, decimals, `NaN`, and `Infinity`. Safe integer range: ±(2⁵³-1).

    ```js
    let age = 25;           // Integer
    let pi = 3.14;          // Decimal
    let notANumber = NaN;   // Not a Number
    let infinity = Infinity;
    let negInfinity = -Infinity;

    console.log(typeof age); // "number"
    console.log(typeof NaN); // "number" (quirk!)
    ```

    <Aside type="tip" title="Checking for NaN">
    Use `Number.isNaN()` to check if a value is NaN. Don't use `=== NaN` because `NaN !== NaN`!

    ```js
    console.log(NaN === NaN);        // false
    console.log(Number.isNaN(NaN));  // true (recommended)
    ```
    </Aside>
  </TabItem>
  <TabItem label="bigint">
    For integers larger than the safe integer limit. Denoted with `n` suffix.

    ```js
    let bigNumber = 123n;
    let veryBig = 9007199254740991n;
    console.log(typeof bigNumber); // "bigint"
    ```

    <Aside type="caution" title="Cannot Mix BigInt and Number">
    ```js
    1n + 1;         // TypeError
    1n + BigInt(1); // 2n
    ```
    </Aside>
  </TabItem>
  <TabItem label="string">
    Text data encoded in UTF-16. Strings are **immutable**.

    ```js
    let name = "JavaScript";
    let greeting = 'Hello World';
    let template = `Hello ${name}`; // Template literal
    ```

    **Common Methods:**
    ```js
    let str = "  Hello World  ";
    str.length;            // 15
    str.toUpperCase();     // "  HELLO WORLD  "
    str.trim();            // "Hello World"
    str.includes("World"); // true
    str.split(" ");        // ["", "", "Hello", "World", "", ""]
    ```
  </TabItem>
  <TabItem label="boolean">
    Only two values: `true` or `false`.

    ```js
    let isActive = true;
    let isComplete = false;
    console.log(typeof isActive); // "boolean"
    ```

    <Aside type="caution" title="The 7 Falsy Values">
    Only these values are falsy. Everything else is truthy!

    ```js
    Boolean(false);     // false
    Boolean(0);         // false
    Boolean("");        // false
    Boolean(null);      // false
    Boolean(undefined); // false
    Boolean(NaN);       // false
    Boolean([]);        // true (empty array is truthy!)
    Boolean({});        // true (empty object is truthy!)
    ```
    </Aside>
  </TabItem>
  <TabItem label="null & undefined">
    - **null**: Represents the **intentional absence** of a value
    - **undefined**: Represents a variable that has been declared but **not assigned**

    ```js
    let emptyValue = null;
    let notAssigned;
    console.log(notAssigned); // undefined
    ```

    | Aspect         | null                   | undefined                           |
    | -------------- | ---------------------- | ----------------------------------- |
    | **Meaning**    | Intentional absence    | Not yet assigned                    |
    | **typeof**     | "object" (bug)         | "undefined"                         |
    | **Assignment** | Must be explicitly set | Default for uninitialized variables |
    | **Equality**   | `null == undefined` ✅ | `null === undefined` ❌             |

    <Aside type="caution" title="typeof null Bug">
    `typeof null` returns `"object"` due to a longstanding bug in JavaScript. `null` is actually a primitive type!
    </Aside>
  </TabItem>
  <TabItem label="symbol">
    Creates **unique** identifiers. Often used for object property keys.

    ```js
    let id = Symbol("id");
    let anotherId = Symbol("id");
    console.log(id === anotherId); // false (each symbol is unique!)
    console.log(typeof id);         // "symbol"
    ```
  </TabItem>
</Tabs>

### The `typeof` Operator

```js
typeof 42;              // "number"
typeof 123n;            // "bigint"
typeof "hello";         // "string"
typeof true;            // "boolean"
typeof undefined;       // "undefined"
typeof Symbol("id");    // "symbol"
typeof null;            // "object" (bug!)
typeof {};              // "object"
typeof [];              // "object"
typeof function() {};   // "function"
```

<Aside type="tip" title="Checking for Arrays">
Use `Array.isArray()` to check if something is an array, since `typeof` returns `"object"` for arrays.

```js
typeof [];           // "object"
Array.isArray([]);   // true
```
</Aside>

## Non-Primitive Types (Objects)

Non-primitive types (also called **reference types**) include Objects, Arrays, Functions, and more. They are stored as **references**, not values.

### Objects

Objects store collections of data as **key-value pairs**.

<Tabs>
  <TabItem label="Create & Access">
    ```js
    // Object literal (recommended)
    let person = {
        name: "Alice",
        age: 25,
        greet: function() {
            console.log(`Hello, I'm ${this.name}`);
        }
    };

    // Accessing properties
    console.log(person.name);    // "Alice" (dot notation)
    console.log(person["age"]);  // 25 (bracket notation)
    person.greet();              // "Hello, I'm Alice"
    ```
  </TabItem>
  <TabItem label="Common Operations">
    ```js
    let obj = { a: 1, b: 2 };

    // Clone (shallow copy)
    let clone1 = Object.assign({}, obj);
    let clone2 = { ...obj }; // Spread operator

    // Iterate
    Object.keys(obj);     // ["a", "b"]
    Object.values(obj);   // [1, 2]
    Object.entries(obj);  // [["a", 1], ["b", 2]]

    // Check property
    "a" in obj;                // true
    obj.hasOwnProperty("a");  // true

    // Delete & Freeze
    delete obj.a;
    Object.freeze(obj);
    ```
  </TabItem>
</Tabs>

## Prototype

Every object in JavaScript has a hidden **prototype** object that it inherits from. When you access a property, JavaScript first looks in the object itself, then in its prototype chain.

```js
function Person(name) {
    this.name = name;
}

// Add method to prototype
Person.prototype.sayHello = function() {
    console.log(`Hello, I'm ${this.name}`);
};

let john = new Person("John");
john.sayHello(); // "Hello, I'm John"

// john doesn't have sayHello directly
console.log(john.hasOwnProperty("sayHello")); // false
```

<Aside type="note" title="Prototype Chain">
When you access `john.sayHello()`, JavaScript:
1. Looks for `sayHello` in `john` → not found
2. Looks in `john.__proto__` (which is `Person.prototype`) → found!
</Aside>

## Prototype Chain (Prototypal Inheritance)

**Prototypal inheritance** allows objects to inherit properties and methods from other objects through the prototype chain.

<Tabs>
  <TabItem label="Constructor Functions">
    ```js
    function Animal(name) {
        this.name = name;
    }

    Animal.prototype.speak = function() {
        console.log(`${this.name} makes a sound`);
    };

    function Dog(name, breed) {
        Animal.call(this, name);
        this.breed = breed;
    }

    Dog.prototype = Object.create(Animal.prototype);
    Dog.prototype.constructor = Dog;

    Dog.prototype.bark = function() {
        console.log(`${this.name} barks!`);
    };

    let dog = new Dog("Buddy", "Golden Retriever");
    dog.speak(); // "Buddy makes a sound" (inherited)
    dog.bark();  // "Buddy barks!" (own method)
    ```
  </TabItem>
  <TabItem label="ES6 Classes">
    ```js
    class Animal {
        constructor(name) {
            this.name = name;
        }
        speak() {
            console.log(`${this.name} makes a sound`);
        }
    }

    class Dog extends Animal {
        constructor(name, breed) {
            super(name);
            this.breed = breed;
        }
        bark() {
            console.log(`${this.name} barks!`);
        }
    }

    let dog = new Dog("Buddy", "Golden Retriever");
    dog.speak(); // "Buddy makes a sound"
    dog.bark();  // "Buddy barks!"
    ```

    <Aside type="tip" title="Modern Alternative">
    ES6 `class` syntax is syntactic sugar over prototypes but is much easier to read and write.
    </Aside>
  </TabItem>
</Tabs>

## Built-in Objects

JavaScript provides many built-in objects that offer useful methods and properties.

| Object      | Purpose                  | Common Methods/Properties                                                |
| ----------- | ------------------------ | ----------------------------------------------------------------------- |
| **Number**  | Work with numbers        | `toFixed()`, `toPrecision()`, `isNaN()`, `isFinite()`                    |
| **Math**    | Mathematical operations  | `Math.PI`, `Math.sqrt()`, `Math.floor()`, `Math.ceil()`, `Math.random()` |
| **Date**    | Work with dates/times    | `getFullYear()`, `getMonth()`, `getDate()`, `toISOString()`              |
| **String**  | String manipulation      | `length`, `toUpperCase()`, `toLowerCase()`, `trim()`, `includes()`       |
| **Array**   | Array operations         | `push()`, `pop()`, `map()`, `filter()`, `reduce()`, `find()`            |
| **Object**  | Object utilities         | `keys()`, `values()`, `entries()`, `assign()`, `freeze()`               |
| **Map**     | Key-value collections    | `set()`, `get()`, `has()`, `delete()`, `clear()`, `size`                 |
| **Set**     | Unique value collections | `add()`, `delete()`, `has()`, `clear()`, `size`                          |
| **RegExp**  | Regular expressions      | `test()`, `exec()`, `match()`, `replace()`                               |
| **Promise** | Async operations         | `then()`, `catch()`, `finally()`, `Promise.all()`                        |

### Examples

```js
// Math
Math.PI;           // 3.141592653589793
Math.sqrt(16);     // 4
Math.random();     // Random number between 0 and 1

// Array
let arr = [1, 2, 3, 4, 5];
arr.map(x => x * 2);      // [2, 4, 6, 8, 10]
arr.filter(x => x > 2);   // [3, 4, 5]
arr.reduce((a, b) => a + b); // 15

// Set (unique values)
let set = new Set([1, 2, 2, 3, 3, 3]);
console.log(set);   // Set { 1, 2, 3 }
set.has(2);          // true
set.size;            // 3
```

<Aside type="note" title="Always Available">
Built-in objects are part of the global scope and can be used anywhere in your code without importing or requiring them.
</Aside>
