## Quick Overview

| Keyword   | Scope            | Hoisting | Re-declare | Reassign | Notes                                               |
| --------- | ---------------- | -------- | ---------- | -------- | --------------------------------------------------- |
| **var**   | Function / Global | Yes      | Yes        | Yes      | Not limited to block `{}`                           |
| **let**   | Block `{}`       | Yes (TDZ)| No         | Yes      | Safer than `var`                                    |
| **const** | Block `{}`       | Yes (TDZ)| No         | No       | Use for constants, or object/array fixed references |

<Aside type="tip" title="Recommendation">
Prefer `const` for values that don't change, `let` for variables that need reassignment. Avoid `var` in modern code!
</Aside>
