In JavaScript, **Indexed Collections** are collections whose elements are accessed by a **numeric index** — essentially *numbered lists*.

---

## Array

### Definition

An `Array` is an **object** that stores **multiple values** of *any data type* in a **determined order**.

```js
let fruits = ["apple", "banana", "orange"];
let mix = [1, "hello", true, { name: "Alice" }];
```

### Accessing & Modifying

```js
let numbers = [10, 20, 30];
console.log(numbers[0]);    // 10
console.log(numbers.length); // 3

numbers[1] = 25;
console.log(numbers); // [10, 25, 30]
```

---

### Method Reference

| Category | Methods | Notes |
| -------- | ------- | ----- |
| **Add / Remove** | `push()`, `pop()`, `shift()`, `unshift()`, `splice()` | `push/pop` O(1), others O(n) |
| **Iterate** | `for`, `for...of`, `forEach()` | `for...of` recommended |
| **Search** | `indexOf()`, `find()`, `findIndex()`, `includes()` | `includes` O(n) |
| **Transform** | `map()`, `filter()`, `reduce()`, `sort()`, `flat()` | Return new array (except sort) |
| **Merge** | `concat()`, `spread (...)` | Does not mutate original |
| **Slice** | `slice()`, `splice()` | `slice` non-mutating, `splice` mutating |

---

### Common Operations

<Tabs>
  <TabItem label="Add / Remove">
    ```js
    let arr = [1, 2, 3];

    arr.push(4);       // [1, 2, 3, 4]   — add to end
    arr.pop();         // [1, 2, 3]       — remove from end
    arr.unshift(0);    // [0, 1, 2, 3]    — add to start
    arr.shift();       // [1, 2, 3]       — remove from start

    // splice: remove 1 element at index 1, insert "a", "b"
    arr.splice(1, 1, "a", "b"); // [1, "a", "b", 3]
    ```
  </TabItem>
  <TabItem label="Transform">
    ```js
    let arr = [1, 2, 3, 4, 5];

    // map — create new array
    let doubled = arr.map(x => x * 2);      // [2, 4, 6, 8, 10]

    // filter — keep matching elements
    let evens = arr.filter(x => x % 2 === 0); // [2, 4]

    // reduce — accumulate to single value
    let sum = arr.reduce((acc, x) => acc + x, 0); // 15

    // flat — flatten nested arrays
    let nested = [1, [2, [3]]];
    nested.flat(Infinity); // [1, 2, 3]
    ```
  </TabItem>
  <TabItem label="Search">
    ```js
    let arr = [10, 20, 30, 40];

    arr.includes(20);              // true
    arr.indexOf(30);               // 2
    arr.find(x => x > 25);        // 30
    arr.findIndex(x => x > 25);   // 2
    ```
  </TabItem>
</Tabs>

### Special Properties

<Aside type="note" title="Arrays in JS are actually Objects">
- Arrays are **objects** with string indices `"0"`, `"1"`, `"2"`, …
- **Not** fixed size — they grow and shrink dynamically
- Elements can be of **different types**
- `typeof [] === "object"` — use `Array.isArray()` to check

```js
Array.isArray([1, 2, 3]); // true
Array.isArray("hello");   // false
```
</Aside>

### Destructuring & Spread

```js
// Destructuring
const [first, second, ...rest] = [1, 2, 3, 4, 5];
// first = 1, second = 2, rest = [3, 4, 5]

// Spread — clone & merge
const a = [1, 2];
const b = [3, 4];
const merged = [...a, ...b]; // [1, 2, 3, 4]

// Spread — shallow clone
const clone = [...a];
```

## TypedArray

### Definition

**TypedArray** is a special array type for storing **raw binary data** with a **fixed type** and **fixed length**.

<CardGrid>
  <Card title="High Performance" icon="rocket">
    Faster access, more memory efficient than regular Arrays
  </Card>
  <Card title="Fixed Type" icon="setting">
    Each element has the same type and byte size
  </Card>
  <Card title="Specialized Use" icon="star">
    WebGL, Canvas, Audio API, File API, AI/ML
  </Card>
</CardGrid>

---

### Structure: ArrayBuffer + View

Typed Arrays are built on two components:

1. **ArrayBuffer** → raw binary memory block
2. **View (TypedArray)** → read/write layer on top of the buffer

```js
// Create a 16-byte memory block
let buffer = new ArrayBuffer(16);

// Create a 32-bit integer "view" (4 bytes per element)
let view = new Int32Array(buffer);
console.log(view.length); // 4 elements (16 / 4)
```

---

### TypedArray Variants

| Type | Bytes/element | Value range |
| ---- | ------------- | ----------- |
| `Int8Array` | 1 | -128 → 127 |
| `Uint8Array` | 1 | 0 → 255 |
| `Uint8ClampedArray` | 1 | 0 → 255 (clamped) |
| `Int16Array` | 2 | -32768 → 32767 |
| `Uint16Array` | 2 | 0 → 65535 |
| `Int32Array` | 4 | -2³¹ → 2³¹-1 |
| `Uint32Array` | 4 | 0 → 2³²-1 |
| `Float32Array` | 4 | 32-bit float |
| `Float64Array` | 8 | 64-bit float |

<Tabs>
  <TabItem label="Empty">

  </TabItem>
  <TabItem label="From array">

  </TabItem>

  </TabItem>

---

### Access & Operations

```js
let arr = new Int16Array([10, 20, 30]);

arr[1];            // 20
arr[1] = 50;       // assign value

// Iterate
for (let val of arr) console.log(val);

// Built-in methods
arr.set([100, 200, 300]);   // bulk assign
arr.subarray(0, 2);         // sub-view (no copy)
```

---

### Converting TypedArray ↔ Array

```js
let typed = new Uint8Array([1, 2, 3]);
let normal = Array.from(typed);       // [1, 2, 3]
let back = new Uint8Array(normal);    // convert back
```

### Real-World Applications

<Tabs>

    ```js
    fetch("image.png")
      .then(res => res.arrayBuffer())
      .then(buf => {
        let bytes = new Uint8Array(buf);
        console.log("Bytes:", bytes.length);
    ```

  <TabItem label="Canvas pixels">
    ```js
    const canvas = document.getElementById("myCanvas");
    const ctx = canvas.getContext("2d");
    const imageData = ctx.getImageData(0, 0, canvas.width, canvas.height);

    // imageData.data is Uint8ClampedArray — RGBA per pixel
    for (let i = 0; i < imageData.data.length; i += 4) {
      imageData.data[i] = 255;     // R
      imageData.data[i + 1] = 0;   // G
      imageData.data[i + 2] = 0;   // B
      // imageData.data[i + 3] — Alpha
    }
    ctx.putImageData(imageData, 0, 0);
    ```
  </TabItem>
</Tabs>

<Aside type="tip" title="Array vs TypedArray">
- Need to store **mixed types** → use `Array`
- Need **high performance** with numeric/binary data → use `TypedArray`
- TypedArray does **not** have `push`, `pop`, `splice` — fixed size!
</Aside>
