## Quick Classification

| Structure | Description | When to use |
| --------- | ----------- | ----------- |
| **Array** | Ordered list, accessed by index | Sequential iteration, push/pop |
| **Object** | Key→value mapping (string/symbol keys) | Config, small records |
| **Map** | Enhanced hash map — key can be *anything* | Object keys, insertion order needed |
| **Set** | Collection of unique values | Deduplication, membership testing |
| **WeakMap / WeakSet** | Weak-referenced object keys/elements | Cache, private state |
| **TypedArray** | High-performance binary arrays | WebGL, audio, ML |
| **JSON** | Data interchange format | HTTP, localStorage, files |

## Common Time Complexities

<Tabs>
  <TabItem label="Array">
    | Operation | Complexity |
    | --------- | ---------- |
    | `push` / `pop` | O(1) |
    | `shift` / `unshift` / `splice` | O(n) |
    | Access `arr[i]` | O(1) |
    | `includes` / `indexOf` | O(n) |
    | `sort` | ~O(n log n) |
  </TabItem>
  <TabItem label="Map / Set">
    | Operation | Complexity |
    | --------- | ---------- |
    | `set` / `add` | O(1) average |
    | `get` / `has` | O(1) average |
    | `delete` | O(1) average |
  </TabItem>
  <TabItem label="Object">
    | Operation | Complexity |
    | --------- | ---------- |
    | Access `obj.key` | O(1) average |
    | `delete obj.key` | O(1) average |
    | `Object.keys()` | O(n) |
  </TabItem>
</Tabs>

<Aside type="tip" title="Which structure to choose?">
- Need an **ordered list** → `Array`
- Need **key→value** with string keys → `Object`
- Need **key→value** with any type as key → `Map`
- Need a **unique collection** → `Set`
- Need **cache that auto-cleans** → `WeakMap` / `WeakSet`
</Aside>
