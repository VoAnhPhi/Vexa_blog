Chào mừng đến với phần Frontend Development! Nơi bạn sẽ học cách xây dựng giao diện web hiện đại.

## Learning Path

1. **Beginner**: HTML/CSS → JavaScript → React basics
2. **Intermediate**: Hooks → State management → API integration
3. **Advanced**: Architecture → Performance → Testing

## Popular Stack

-   **React** + **TypeScript** + **Vite**
-   **TailwindCSS** hoặc **CSS Modules**
-   **React Query** cho data fetching
-   **Zustand** hoặc **Redux** cho state management
