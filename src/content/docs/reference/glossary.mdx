# Glossary

Tổng hợp thuật ngữ technical phổ biến trong software development.

## A

**API (Application Programming Interface)**
Interface để các ứng dụng giao tiếp với nhau.

**Async/Await**
Cú pháp để xử lý asynchronous operations trong JavaScript.

## B

**Backend**
Server-side của ứng dụng, xử lý logic và data.

**Bundle**
File JavaScript được compile từ nhiều modules.

## C

**Callback**
Function được passed vào function khác để execute sau.

**CI/CD**
Continuous Integration / Continuous Deployment - automated build và deploy.

**Closure**
Function có thể access variables từ outer scope.

**Component**
Reusable UI element trong frontend frameworks.

## D

**Database**
Nơi lưu trữ data có cấu trúc.

**Deployment**
Process đưa code lên production environment.

**DevTools**
Browser developer tools để debug.

## E

**Environment Variables**
Configuration values stored outside code.

**Event Loop**
JavaScript's mechanism để handle async operations.

## F

**Framework**
Structure/foundation để build applications.

**Frontend**
Client-side của ứng dụng, giao diện users tương tác.

## G

**Git**
Version control system.

**GraphQL**
Query language cho APIs.

## H

**Hook**
React function để use state và lifecycle features.

**HTTP**
HyperText Transfer Protocol - giao thức web.

## J

**JSON**
JavaScript Object Notation - data format.

**JWT**
JSON Web Token - authentication token format.

## M

**Middleware**
Functions chạy giữa request và response.

**MVC**
Model-View-Controller - architecture pattern.

## N

**Node.js**
JavaScript runtime cho server-side.

**NPM**
Node Package Manager.

## O

**ORM**
Object-Relational Mapping - database abstraction.

## P

**Promise**
JavaScript object representing async operation result.

**Props**
Properties passed to React components.

## R

**REST**
Representational State Transfer - API architecture style.

**Route**
URL path mapping to specific code/component.

## S

**SPA**
Single Page Application.

**SQL**
Structured Query Language - database query language.

**State**
Data that changes over time in an application.

## T

**TypeScript**
JavaScript superset with static typing.

## U

**UI/UX**
User Interface / User Experience.

**URL**
Uniform Resource Locator - web address.

## V

**Virtual DOM**
In-memory representation của real DOM (React).

## W

**Webhook**
HTTP callback triggered by event.

**WebSocket**
Real-time two-way communication protocol.
