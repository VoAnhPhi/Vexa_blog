# Functions - Hàm trong JavaScript

Functions (hàm) là block code có thể tái sử dụng để thực hiện một nhiệm vụ cụ thể.

## Function Declaration

Cách khai báo hàm truyền thống:

```javascript
function greet(name) {
	return `Hello, ${name}!`;
}

const message = greet("Phi");
console.log(message); // "Hello, Phi!"
```

## Function Expression

Gán hàm vào một biến:

```javascript
const greet = function (name) {
	return `Hello, ${name}!`;
};

console.log(greet("Phi")); // "Hello, Phi!"
```

## Arrow Functions

Cú pháp ngắn gọn hiện đại (ES6+):

```javascript
// Cú pháp đầy đủ
const greet = (name) => {
	return `Hello, ${name}!`;
};

// Cú pháp ngắn gọn (implicit return)
const greet2 = (name) => `Hello, ${name}!`;

// Một parameter không cần ()
const square = (x) => x * x;

// Không có parameter
const sayHi = () => "Hi!";
```

## Parameters và Arguments

### Default Parameters

```javascript
function greet(name = "Guest") {
	return `Hello, ${name}!`;
}

console.log(greet()); // "Hello, Guest!"
console.log(greet("Phi")); // "Hello, Phi!"
```

### Rest Parameters

```javascript
function sum(...numbers) {
	return numbers.reduce((total, num) => total + num, 0);
}

console.log(sum(1, 2, 3)); // 6
console.log(sum(1, 2, 3, 4, 5)); // 15
```

## Return Values

```javascript
// Trả về giá trị
function add(a, b) {
	return a + b;
}

// Trả về object
function createUser(name, age) {
	return {
		name: name,
		age: age,
		isActive: true,
	};
}

// Không return → undefined
function log(message) {
	console.log(message);
	// Không có return
}
```

## Callback Functions

Function được truyền vào function khác:

```javascript
function processData(data, callback) {
	const result = data * 2;
	callback(result);
}

processData(5, (result) => {
	console.log(result); // 10
});

// Array methods với callback
const numbers = [1, 2, 3, 4, 5];
numbers.forEach((num) => console.log(num));
```

## Higher-Order Functions

Functions nhận function làm tham số hoặc trả về function:

```javascript
// Map
const numbers = [1, 2, 3, 4];
const doubled = numbers.map((x) => x * 2);
// [2, 4, 6, 8]

// Filter
const evens = numbers.filter((x) => x % 2 === 0);
// [2, 4]

// Reduce
const sum = numbers.reduce((acc, x) => acc + x, 0);
// 10
```

## IIFE (Immediately Invoked Function Expression)

```javascript
(function () {
	console.log("Chạy ngay lập tức!");
})();

// Arrow function IIFE
(() => {
	console.log("IIFE với arrow function!");
})();
```

## Best Practices

### 1. Đặt tên function có ý nghĩa

```javascript
// ✅ Good
function calculateTotalPrice(items) {
	return items.reduce((sum, item) => sum + item.price, 0);
}

// ❌ Bad
function calc(x) {
	return x.reduce((s, i) => s + i.p, 0);
}
```

### 2. Functions nên làm một việc

```javascript
// ✅ Good - Single responsibility
function validateEmail(email) {
	return email.includes("@");
}

function sendEmail(to, subject, body) {
	// Send email logic
}

// ❌ Bad - Làm quá nhiều việc
function validateAndSendEmail(email, subject, body) {
	if (!email.includes("@")) return false;
	// send email...
	// update database...
	// log...
}
```

### 3. Giới hạn số parameters

```javascript
// ✅ Good - Dùng object cho nhiều parameters
function createUser({ name, email, age, city }) {
	return { name, email, age, city };
}

createUser({
	name: "Phi",
	email: "phi@example.com",
	age: 25,
	city: "Hanoi",
});

// ❌ Bad - Quá nhiều parameters
function createUser2(name, email, age, city, country, phone) {
	// ...
}
```

## Pure Functions

Function không có side effects:

```javascript
// ✅ Pure function
function add(a, b) {
	return a + b; // Chỉ phụ thuộc vào input
}

// ❌ Impure function - có side effect
let total = 0;
function addToTotal(value) {
	total += value; // Thay đổi biến bên ngoài
	return total;
}
```

## Bài tập

```javascript
// 1. Viết function tính diện tích hình chữ nhật
function calculateArea(width, height) {
	return width * height;
}

// 2. Viết function kiểm tra số chẵn
const isEven = (num) => num % 2 === 0;

// 3. Viết function lấy tên đầy đủ
function getFullName(firstName, lastName) {
	return `${firstName} ${lastName}`;
}

// 4. Viết function filter số lẻ
const filterOdd = (numbers) => numbers.filter((n) => n % 2 !== 0);
```

## Tóm tắt

| Loại        | Cú pháp                      | Khi nào dùng?               |
| ----------- | ---------------------------- | --------------------------- |
| Declaration | `function name() {}`         | Functions cần hoisting      |
| Expression  | `const name = function() {}` | Gán vào biến                |
| Arrow       | `const name = () => {}`      | Cú pháp ngắn gọn, callbacks |
