# Variables - Biến trong JavaScript

Biến là nơi lưu trữ dữ liệu trong lập trình. JavaScript có 3 cách khai báo biến: `var`, `let`, và `const`.

## Khai báo biến

### `let` - Biến có thể thay đổi giá trị

```javascript
let name = "Phi";
let age = 25;

// Có thể thay đổi giá trị
name = "Anh";
age = 26;
```

**Đặc điểm:**

-   ✅ Có thể thay đổi giá trị
-   ✅ Block-scoped (chỉ tồn tại trong block `{}`)
-   ✅ Không thể khai báo lại trong cùng scope

### `const` - Hằng số (không đổi)

```javascript
const PI = 3.14159;
const API_URL = "https://api.example.com";

// ❌ Không thể thay đổi
// PI = 3.14; // Error!
```

**Đặc điểm:**

-   ✅ Không thể thay đổi giá trị (immutable)
-   ✅ Block-scoped
-   ⚠️ Phải gán giá trị ngay khi khai báo

**Lưu ý với Object và Array:**

```javascript
const user = { name: "Phi" };
user.name = "Anh"; // ✅ OK - Thay đổi property
// user = {}; // ❌ Error - Không thể gán lại

const numbers = [1, 2, 3];
numbers.push(4); // ✅ OK - Thay đổi nội dung
// numbers = []; // ❌ Error - Không thể gán lại
```

### `var` - Cách khai báo cũ (⚠️ Tránh dùng)

```javascript
var oldWay = "Không nên dùng";
```

**Tại sao không nên dùng `var`?**

-   ❌ Function-scoped (khó kiểm soát)
-   ❌ Có thể khai báo lại → dễ gây bug
-   ❌ Hoisting behavior khó hiểu

## Best Practices

### 1. Ưu tiên `const`, dùng `let` khi cần

```javascript
// ✅ Good
const MAX_USERS = 100;
let currentUsers = 0;

// ❌ Avoid
var total = 0;
```

### 2. Đặt tên biến có ý nghĩa

```javascript
// ✅ Good - Rõ ràng
const userEmail = "phi@example.com";
const isLoggedIn = true;
const itemsPerPage = 10;

// ❌ Bad - Không rõ nghĩa
const x = "phi@example.com";
const flag = true;
const n = 10;
```

### 3. Naming conventions

```javascript
// camelCase cho biến và function
const firstName = "Phi";
const getUserData = () => {};

// UPPER_SNAKE_CASE cho constants
const API_KEY = "abc123";
const MAX_RETRY = 3;

// PascalCase cho Class/Component
class UserProfile {}
const MyComponent = () => {};
```

## Scope - Phạm vi biến

### Block Scope

```javascript
{
	let blockVar = "Chỉ tồn tại trong block này";
	const BLOCK_CONST = 100;
	console.log(blockVar); // ✅ OK
}

// console.log(blockVar); // ❌ Error: not defined
```

### Function Scope

```javascript
function greet() {
	let message = "Hello";
	console.log(message); // ✅ OK
}

// console.log(message); // ❌ Error: not defined
```

### Global Scope

```javascript
// Global variable - Truy cập được ở mọi nơi
const SITE_NAME = "Vexa Blog";

function displaySite() {
	console.log(SITE_NAME); // ✅ OK
}
```

## Data Types

Biến có thể lưu nhiều kiểu dữ liệu:

```javascript
// String (Chuỗi)
const name = "Phi";
const greeting = "Hello";
const template = `My name is ${name}`;

// Number (Số)
const age = 25;
const price = 99.99;
const negative = -10;

// Boolean (Đúng/Sai)
const isActive = true;
const hasPermission = false;

// Array (Mảng)
const colors = ["red", "green", "blue"];
const numbers = [1, 2, 3, 4, 5];

// Object (Đối tượng)
const user = {
	name: "Phi",
	age: 25,
	email: "phi@example.com",
};

// Null và Undefined
const empty = null;
let notAssigned; // undefined
```

## Template Literals

Cách hiện đại để làm việc với string:

```javascript
const name = "Phi";
const age = 25;

// ✅ Template literal - Dễ đọc
const intro = `My name is ${name} and I'm ${age} years old.`;

// ❌ String concatenation - Khó đọc
const intro2 = "My name is " + name + " and I'm " + age + " years old.";

// Multi-line string
const html = `
  <div>
    <h1>${name}</h1>
    <p>Age: ${age}</p>
  </div>
`;
```

## Destructuring

Cách ngắn gọn để lấy giá trị từ object/array:

```javascript
// Object destructuring
const user = {
	name: "Phi",
	age: 25,
	email: "phi@example.com",
};

const { name, email } = user;
console.log(name); // "Phi"
console.log(email); // "phi@example.com"

// Array destructuring
const colors = ["red", "green", "blue"];
const [first, second] = colors;
console.log(first); // "red"
console.log(second); // "green"
```

## Bài tập thực hành

```javascript
// Bài 1: Khai báo thông tin cá nhân
const yourName = "Tên bạn";
const yourAge = 20;
const yourCity = "Thành phố";

// Bài 2: Tính toán
const price = 100;
const quantity = 3;
const total = price * quantity;

// Bài 3: Template literal
const message = `Tổng tiền: ${total} VND`;

// Bài 4: Array operations
const fruits = ["apple", "banana"];
fruits.push("orange");
console.log(fruits);
```

## Tóm tắt

| Từ khóa | Thay đổi được? | Scope    | Khi nào dùng?                         |
| ------- | -------------- | -------- | ------------------------------------- |
| `const` | ❌ Không       | Block    | Mặc định - Dùng cho giá trị không đổi |
| `let`   | ✅ Có          | Block    | Khi cần thay đổi giá trị              |
| `var`   | ✅ Có          | Function | ⚠️ Tránh dùng                         |
