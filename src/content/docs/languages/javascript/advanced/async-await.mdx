# Async/Await - Lập trình bất đồng bộ

Async/Await là cách hiện đại để xử lý asynchronous code trong JavaScript, giúp code dễ đọc hơn callbacks và promises.

## Promises

### Tạo Promise

```javascript
const promise = new Promise((resolve, reject) => {
	// Asynchronous operation
	setTimeout(() => {
		const success = true;

		if (success) {
			resolve("Success data");
		} else {
			reject("Error message");
		}
	}, 1000);
});
```

### Sử dụng Promise

```javascript
promise
	.then((data) => {
		console.log(data); // "Success data"
	})
	.catch((error) => {
		console.error(error);
	})
	.finally(() => {
		console.log("Done");
	});
```

## Async/Await

Cú pháp ngắn gọn hơn cho promises:

```javascript
async function fetchData() {
	try {
		const response = await fetch("https://api.example.com/data");
		const data = await response.json();
		console.log(data);
	} catch (error) {
		console.error("Error:", error);
	}
}
```

### So sánh: Promises vs Async/Await

```javascript
// ❌ Promises - nhiều .then()
function getUserData() {
	return fetch("/api/user")
		.then((response) => response.json())
		.then((user) => {
			return fetch(`/api/posts/${user.id}`);
		})
		.then((response) => response.json())
		.then((posts) => {
			return { user, posts };
		})
		.catch((error) => {
			console.error(error);
		});
}

// ✅ Async/Await - dễ đọc hơn
async function getUserData() {
	try {
		const userResponse = await fetch("/api/user");
		const user = await userResponse.json();

		const postsResponse = await fetch(`/api/posts/${user.id}`);
		const posts = await postsResponse.json();

		return { user, posts };
	} catch (error) {
		console.error(error);
	}
}
```

## Async Functions

### Async function luôn return Promise

```javascript
async function greet() {
	return "Hello"; // Tự động wrap trong Promise
}

greet().then((message) => console.log(message)); // "Hello"

// Tương đương với:
function greet() {
	return Promise.resolve("Hello");
}
```

### Await chỉ dùng trong async function

```javascript
// ✅ OK
async function example() {
  const data = await fetchData();
}

// ❌ Error
function example() {
  const data = await fetchData(); // SyntaxError!
}
```

## Error Handling

### Try/Catch

```javascript
async function fetchUser(id) {
	try {
		const response = await fetch(`/api/users/${id}`);

		if (!response.ok) {
			throw new Error(`HTTP error! status: ${response.status}`);
		}

		const user = await response.json();
		return user;
	} catch (error) {
		console.error("Failed to fetch user:", error);
		throw error; // Re-throw nếu cần
	}
}
```

### Catch Promise

```javascript
// Cách 1: try/catch
async function example1() {
	try {
		const data = await riskyOperation();
	} catch (error) {
		console.error(error);
	}
}

// Cách 2: .catch() trên await
async function example2() {
	const data = await riskyOperation().catch((err) => {
		console.error(err);
		return null; // fallback value
	});
}
```

## Parallel vs Sequential

### Sequential (tuần tự)

```javascript
// Chờ từng cái một - CHẬM
async function sequential() {
	const user = await fetchUser(); // 1s
	const posts = await fetchPosts(); // 1s
	const comments = await fetchComments(); // 1s
	// Tổng: 3s
}
```

### Parallel (song song)

```javascript
// Chạy đồng thời - NHANH
async function parallel() {
	const [user, posts, comments] = await Promise.all([fetchUser(), fetchPosts(), fetchComments()]);
	// Tổng: ~1s (thời gian của request chậm nhất)
}
```

## Promise Methods

### Promise.all() - Tất cả phải thành công

```javascript
async function fetchAllData() {
	try {
		const [users, posts, comments] = await Promise.all([fetch("/api/users"), fetch("/api/posts"), fetch("/api/comments")]);

		// Tất cả request thành công
	} catch (error) {
		// Một trong số fail → toàn bộ fail
		console.error("At least one request failed:", error);
	}
}
```

### Promise.allSettled() - Đợi tất cả, không quan tâm kết quả

```javascript
async function fetchAllDataRobust() {
	const results = await Promise.allSettled([fetch("/api/users"), fetch("/api/posts"), fetch("/api/comments")]);

	results.forEach((result, index) => {
		if (result.status === "fulfilled") {
			console.log(`Request ${index} succeeded:`, result.value);
		} else {
			console.log(`Request ${index} failed:`, result.reason);
		}
	});
}
```

### Promise.race() - Lấy kết quả đầu tiên

```javascript
async function fetchWithTimeout(url, timeout = 5000) {
	const fetchPromise = fetch(url);
	const timeoutPromise = new Promise((_, reject) => {
		setTimeout(() => reject(new Error("Timeout")), timeout);
	});

	// Lấy promise nào resolve/reject trước
	return Promise.race([fetchPromise, timeoutPromise]);
}
```

### Promise.any() - Lấy thành công đầu tiên

```javascript
async function fetchFromMirrors() {
	try {
		const data = await Promise.any([
			fetch("https://mirror1.example.com/data"),
			fetch("https://mirror2.example.com/data"),
			fetch("https://mirror3.example.com/data"),
		]);
		// Lấy response từ server nhanh nhất
		return data;
	} catch (error) {
		// Tất cả đều fail
		console.error("All mirrors failed");
	}
}
```

## Patterns thực tế

### Retry Logic

```javascript
async function fetchWithRetry(url, retries = 3) {
	for (let i = 0; i < retries; i++) {
		try {
			const response = await fetch(url);
			if (response.ok) {
				return await response.json();
			}
		} catch (error) {
			if (i === retries - 1) throw error; // Lần cuối → throw
			console.log(`Retry ${i + 1}/${retries}...`);
			await sleep(1000 * (i + 1)); // Exponential backoff
		}
	}
}

function sleep(ms) {
	return new Promise((resolve) => setTimeout(resolve, ms));
}
```

### Queue với concurrency limit

```javascript
async function processQueue(tasks, concurrency = 3) {
	const results = [];
	const executing = [];

	for (const task of tasks) {
		const promise = task().then((result) => {
			executing.splice(executing.indexOf(promise), 1);
			return result;
		});

		results.push(promise);
		executing.push(promise);

		if (executing.length >= concurrency) {
			await Promise.race(executing);
		}
	}

	return Promise.all(results);
}

// Sử dụng
const tasks = urls.map((url) => () => fetch(url));
await processQueue(tasks, 5); // Chỉ 5 requests đồng thời
```

### Timeout wrapper

```javascript
function withTimeout(promise, timeoutMs) {
	return Promise.race([promise, new Promise((_, reject) => setTimeout(() => reject(new Error("Timeout")), timeoutMs))]);
}

// Sử dụng
try {
	const data = await withTimeout(fetch("/api/slow"), 5000);
} catch (error) {
	console.error("Request timed out or failed");
}
```

## Best Practices

### 1. Luôn handle errors

```javascript
// ❌ Bad
async function bad() {
	const data = await fetch("/api"); // Nếu fail → unhandled rejection
}

// ✅ Good
async function good() {
	try {
		const data = await fetch("/api");
	} catch (error) {
		console.error("Error:", error);
	}
}
```

### 2. Tránh await trong loops nếu không cần sequential

```javascript
// ❌ Bad - Sequential, chậm
async function bad(ids) {
	const results = [];
	for (const id of ids) {
		const data = await fetch(`/api/${id}`);
		results.push(data);
	}
	return results;
}

// ✅ Good - Parallel, nhanh
async function good(ids) {
	const promises = ids.map((id) => fetch(`/api/${id}`));
	return Promise.all(promises);
}
```

### 3. Sử dụng Promise.allSettled khi muốn tất cả kết quả

```javascript
// ✅ Good - Lấy được kết quả của tất cả
const results = await Promise.allSettled([fetchUsers(), fetchPosts(), fetchComments()]);

// Xử lý riêng từng kết quả
const users = results[0].status === "fulfilled" ? results[0].value : [];
```

## Bài tập

```javascript
// 1. Fetch với timeout
async function fetchWithTimeout(url, timeout) {
	// TODO: implement

// 2. Sequential processing với delay
async function processWithDelay(items, delay) {
	for (const item of items) {
		await processItem(item);
		await sleep(delay);
	}
}

// 3. Batch processing
async function processBatch(items, batchSize) {
	for (let i = 0; i < items.length; i += batchSize) {
		const batch = items.slice(i, i + batchSize);
		await Promise.all(batch.map((item) => processItem(item)));
	}
}
```

## Tóm tắt

-   **async/await**: Cú pháp đơn giản hơn Promises
-   **Promise.all()**: Parallel, tất cả phải thành công
-   **Promise.allSettled()**: Lấy tất cả kết quả
-   **try/catch**: Bắt lỗi async code
-   **Parallel > Sequential**: Khi có thể
