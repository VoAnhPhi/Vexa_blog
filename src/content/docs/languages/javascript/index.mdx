# JavaScript

JavaScript là ngôn ngữ lập trình phổ biến nhất thế giới, được sử dụng để tạo ra các website và ứng dụng web tương tác.

## 📖 Nội dung học

### 🔰 Cơ Bản (Basics)

Nền tảng JavaScript mà mọi developer cần biết:

-   **[Variables](/languages/javascript/basics/variables/)** - Khai báo biến: var, let, const
-   **[Functions](/languages/javascript/basics/functions/)** - Function declaration, expression, arrow functions
-   **[Control Flow](/languages/javascript/basics/control-flow/)** - If/else, loops, switch

### 🚀 Nâng Cao (Advanced)

Các concept quan trọng để master JavaScript:

-   **[Closures](/languages/javascript/advanced/closures/)** - Scope, lexical environment
-   **[Async/Await](/languages/javascript/advanced/async-await/)** - Promises, async programming
-   **[Event Loop](/languages/javascript/advanced/event-loop/)** - Cách JavaScript xử lý bất đồng bộ

### 🎯 Patterns

-   **[JavaScript Patterns](/languages/javascript/patterns/)** - Design patterns và best practices

## Tại sao học JavaScript?

1. **Universal Language** - Chạy trên browser, server (Node.js), mobile (React Native)
2. **Huge Ecosystem** - npm, frameworks, libraries vô số
3. **High Demand** - Skill được tìm kiếm nhất trong ngành IT
4. **Beginner Friendly** - Cú pháp dễ học, feedback ngay lập tức

## Yêu cầu tiên quyết

-   Hiểu biết cơ bản về HTML/CSS
-   Logic tư duy cơ bản
-   Không cần kinh nghiệm lập trình trước đó
