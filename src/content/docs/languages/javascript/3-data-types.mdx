### Đặc điểm Primitive Types

<Aside type="note" title="Đặc điểm quan trọng">
- **Bất biến** (immutable) - không thể thay đổi giá trị
- **So sánh theo giá trị** - hai biến có cùng giá trị sẽ bằng nhau
- **Copy giá trị** - khi gán là copy giá trị, không phải tham chiếu
</Aside>

### Kiểm tra kiểu với `typeof`

```js
typeof 42;           // 'number'
typeof 123n;         // 'bigint'
typeof "hello";      // 'string'
typeof true;         // 'boolean'
typeof undefined;    // 'undefined'
typeof Symbol("id"); // 'symbol'
typeof null;         // 'object' (quirk lịch sử - BUG!)
```

<Aside type="caution" title="Lưu ý về typeof null">
`typeof null` trả về `'object'` - đây là một bug lịch sử của JavaScript, không phải hành vi mong đợi!
</Aside>

## Non-primitive Types (Objects)

### Non-primitive là gì?

Trong JavaScript, **Non-primitive** (hay **Reference types**) bao gồm **Objects**, **Arrays**, **Functions**, **Date**, v.v. Các kiểu dữ liệu này được lưu trữ dưới dạng **tham chiếu** thay vì giá trị trực tiếp.

### Object

Object là một kiểu dữ liệu dùng để lưu trữ một tập hợp các giá trị dưới dạng các cặp **key-value** (khóa-giá trị).

<Tabs>
  <TabItem label="Tạo Object">
    ```js
    // Cách 1: Object literal (khuyến nghị)
    let person = {
        name: "Alice",
        age: 25
    };

    // Cách 2: Sử dụng new Object()
    let person2 = new Object();
    person2.name = "Alice";
    person2.age = 25;
    ```
  </TabItem>
  <TabItem label="Truy cập thuộc tính">
    ```js
    // Dot notation
    console.log(person.name);    // "Alice"

    // Bracket notation
    console.log(person["age"]);  // 25
    ```
  </TabItem>
</Tabs>

### Các thao tác phổ biến với Object

| Thao tác | Phương thức/Cú pháp |
| -------- | ------------------- |
| **Tạo & clone/merge** | literal `{}`, `Object.assign`, spread `{...a}`, `structuredClone` |
| **Đọc/ghi/xoá thuộc tính** | dot `obj.x`, bracket `obj['x']`, gán, `delete` |
| **Duyệt** | `for...in`, `Object.keys/values/entries` |
| **Bất biến** | `Object.freeze/seal` |
| **Kiểm tra** | `in`, `hasOwnProperty`, `?.` (optional chaining), `??` (nullish) |

## Prototype

**Prototype** là một đối tượng ẩn mà mỗi đối tượng trong JavaScript kế thừa từ đó. Khi bạn truy cập một thuộc tính hoặc phương thức của đối tượng, JavaScript sẽ tìm kiếm trong chính đối tượng, nếu không tìm thấy, nó sẽ tìm trong **prototype** của đối tượng đó.

```js
function Person(name) {
    this.name = name;
}

Person.prototype.sayHello = function() {
    console.log("Hello, " + this.name);
};

let john = new Person("John");
john.sayHello(); // "Hello, John"
```

<Aside type="note" title="Cách hoạt động của Prototype">
- **Prototype của `Person`** có một phương thức `sayHello`
- Khi gọi `john.sayHello()`, JavaScript tìm trong `john`, không thấy, sau đó tìm trong **prototype** của `Person`
</Aside>

## Prototype Chain

**Prototypal Inheritance** cho phép đối tượng kế thừa các thuộc tính và phương thức từ một đối tượng khác thông qua prototype.

```js
function Animal(name) {
    this.name = name;
}

Animal.prototype.speak = function() {
    console.log(this.name + " makes a sound");
};

function Dog(name, breed) {
    Animal.call(this, name); // Gọi constructor của Animal
    this.breed = breed;
}

// Kế thừa từ Animal
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

Dog.prototype.bark = function() {
    console.log(this.name + " barks");
};

let dog1 = new Dog("Buddy", "Golden Retriever");
dog1.speak(); // "Buddy makes a sound" (Kế thừa từ Animal)
dog1.bark();  // "Buddy barks" (Phương thức riêng của Dog)
```

## Built-in Objects

Built-in objects là các đối tượng được tích hợp sẵn trong ngôn ngữ, có thể sử dụng ở mọi nơi trong chương trình mà không cần phải khai báo hoặc import thêm.

### Một số Built-in Objects phổ biến

| Đối tượng   | Chức năng chính                                                                       |
| ----------- | ------------------------------------------------------------------------------------- |
| **Number**  | Làm việc với số: `toFixed()`, `toPrecision()`, `isNaN()`, `isFinite()`                |
| **Math**    | Toán học: `Math.PI`, `Math.sqrt()`, `Math.pow()`, `Math.floor()`, `Math.random()`     |
| **Date**    | Thời gian: `getFullYear()`, `getMonth()`, `getDate()`, `toDateString()`               |
| **String**  | Chuỗi: `length`, `toUpperCase()`, `toLowerCase()`, `substring()`, `split()`, `trim()` |
| **Boolean** | Logic: `valueOf()`, `toString()`                                                      |
| **Array**   | Mảng: `push()`, `pop()`, `map()`, `filter()`, `reduce()`, `forEach()`, `find()`       |
| **Object**  | Đối tượng: `keys()`, `values()`, `entries()`, `assign()`, `hasOwnProperty()`          |
| **Map**     | Bản đồ: `set()`, `get()`, `has()`, `delete()`, `clear()`                              |
| **Set**     | Tập hợp: `add()`, `delete()`, `has()`, `clear()`                                      |

<Aside type="tip" title="Ghi nhớ">
- Các **built-in objects** luôn có sẵn trong **global scope**
- Bạn có thể dùng chúng **trực tiếp mà không cần import**
- Một số khác như `RegExp`, `Promise`, `Error` cũng là **built-in objects**
</Aside>
