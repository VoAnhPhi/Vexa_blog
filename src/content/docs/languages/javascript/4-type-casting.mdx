## Implicit Type Casting (Ép Kiểu Ngầm)

JavaScript sẽ tự đổi kiểu để "làm vừa" toán tử/ngữ cảnh:

### 1. Toán tử số học (trừ, nhân, chia…) ép về Number

```js
"5" * 2;    // 10   -> "5" bị ép thành 5
"10" - 1;   // 9
"6" / "3";  // 2
```

### 2. Toán tử `+` đặc biệt: nếu có string → nối chuỗi

```js
1 + "2";   // "12" (số → chuỗi)
"2" + 1;   // "21"
```

### 3. So sánh lỏng `==` tự ép kiểu

```js
0 == false;          // true (đã coercion)
"" == 0;             // true
null == undefined;   // true
```

<Aside type="caution" title="Khuyến nghị">
Dùng `===` để không ép kiểu ngầm, tránh bug khó debug!
</Aside>

### 4. Ép sang Boolean trong điều kiện (truthy/falsy)

```js
if ("hello") { /* chạy vì truthy */ }
!!"hello";  // true
!!0;        // false
!![];       // true
!!{};       // true
```

**Các giá trị falsy trong JavaScript:**

| Giá trị | Mô tả |
| ------- | ----- |
| `false` | Boolean false |
| `0`, `-0` | Số 0 |
| `""` | Empty string |
| `null` | Null |
| `undefined` | Undefined |
| `NaN` | Not a Number |

### 5. Một số toán tử/ngữ cảnh khác gây coercion

```js
// Unary plus
+"42";           // 42

// Bitwise (ép về 32-bit int)
3.9 | 0;         // 3

// So sánh < , >
"2" > "12";      // true (so sánh chuỗi theo từ vựng)
"2" > 12;        // false (đã ép về số)
```

## Explicit Type Casting (Ép Kiểu Tường Minh)

Bạn **chỉ định rõ** muốn đổi sang kiểu gì:

<Tabs>
  <TabItem label="String → Number">
    ```js
    Number("3.14");         // 3.14 (chuẩn, fail -> NaN)
    parseInt("08", 10);     // 8 (NHỚ truyền radix)
    parseFloat("2.5px");    // 2.5 (dừng ở chỗ không phải số)
    +"42";                  // 42 (nhanh nhưng kém rõ ràng)
    ```

    <Aside type="tip" title="Lưu ý">
    `Number("42px")` → `NaN`, trong khi `parseInt("42px", 10)` → `42`
    </Aside>
  </TabItem>
  <TabItem label="Number → String">
    ```js
    String(123);         // "123"
    (123).toString();    // "123"
    123 + "";            // "123" (ép ngầm)
    ```
  </TabItem>
  <TabItem label="Any → Boolean">
    ```js
    Boolean(0);      // false
    Boolean("hi");   // true
    !!value;         // shorthand (double NOT)
    ```
  </TabItem>
  <TabItem label="Object → Primitive">
    JavaScript gọi tuần tự `valueOf()` rồi `toString()`; bạn có thể override:

    ```js
    const money = {
        amount: 1000,
        valueOf() { return this.amount; }
    };
    money + 500;   // 1500
    ```
  </TabItem>
</Tabs>

## So Sánh Nhanh 3 Khái Niệm

| Khái niệm | Định nghĩa | Ai kích hoạt? | Ví dụ JS |
| --------- | ---------- | ------------- | -------- |
| **Type coercion** | Chuyển kiểu **ngầm** | JS/ngữ cảnh tự làm | `"5"*2 → 10`, `0 == false → true` |
| **Implicit conversion** | Từ đồng nghĩa của coercion | JS/ngữ cảnh tự làm | `if("hi"){}`, `+"42" // 42` |
| **Explicit casting** | Bạn **chỉ định** kiểu đích | Lập trình viên | `Number("3.14")`, `parseInt("08",10)` |

## Best Practices (Tránh Bug)

<Steps>
1. **Dùng `===` thay cho `==`** để tránh coercion ngoài ý muốn

   ```js
   // BAD
   if (value == null) { }

   // GOOD
   if (value === null || value === undefined) { }
   ```

2. **Khi cần số thực**, ưu tiên `Number()`; khi cần **nguyên** từ chuỗi, dùng `parseInt(str, 10)`

   ```js
   // Số thập phân
   const price = Number("19.99");

   // Số nguyên
   const age = parseInt("25", 10);
   ```

3. **Ép tường minh** ở rìa hệ thống (input UI/API/file) thay vì trông chờ JS ép hộ

   ```js
   const userInput = document.getElementById("age").value;
   const age = Number(userInput); // Ép tường minh

   if (isNaN(age)) {
       console.error("Invalid age");
   }
   ```

4. **Tránh trộn `BigInt` với `Number`** trong 1 biểu thức

   ```js
   1n + 1;         // TypeError
   1n + BigInt(1); // OK: 2n
   ```
</Steps>

## Ví Dụ Thực Tế

<Tabs>
  <TabItem label="Validation Input">
    ```js
    function validateAge(input) {
        const age = Number(input);

        if (isNaN(age)) {
            return "Vui lòng nhập số hợp lệ";
        }

        if (age < 0 || age > 150) {
            return "Tuổi không hợp lệ";
        }

        return "OK";
    }
    ```
  </TabItem>
  <TabItem label="So sánh an toàn">
    ```js
    // BAD - coercion không mong muốn
    if (userInput == 0) { }

    // GOOD - explicit check
    if (Number(userInput) === 0) { }
    ```
  </TabItem>
  <TabItem label="Chuyển đổi từ API">
    ```js
    // Data từ API thường là string
    const apiResponse = {
        price: "19.99",
        quantity: "5"
    };

    // Ép kiểu tường minh
    const total = Number(apiResponse.price) * Number(apiResponse.quantity);
    console.log(total); // 99.95
    ```
  </TabItem>
</Tabs>
