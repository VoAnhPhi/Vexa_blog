# Giới Thiệu JavaScript

## **JavaScript là gì?**

JavaScript, thường được viết tắt là JS, là một ngôn ngữ lập trình thuộc các công nghệ cốt lõi của World Wide Web, cùng với HTML và CSS. JavaScript cho phép chúng ta thêm tính tương tác vào các trang web, ví dụ: bạn có thể thấy các slider, alerts, click interactions, popups, v.v. trên các trang web khác nhau - tất cả đều được xây dựng bằng JavaScript.

Ngoài việc được sử dụng trong trình duyệt, JavaScript còn được sử dụng trong các môi trường không phải trình duyệt như:

-   **Node.js** - Viết code server-side bằng JavaScript
-   **Electron** - Viết ứng dụng desktop
-   **React Native** - Phát triển ứng dụng mobile

## **Lịch Sử JavaScript**

JavaScript ban đầu được tạo ra bởi **Brendan Eich** của NetScape và lần đầu tiên được công bố trong một thông cáo báo chí của Netscape vào năm 1995.

Ngôn ngữ này có lịch sử đặt tên khá kỳ lạ:

1. **Mocha** - Tên ban đầu do người tạo ra đặt
2. **LiveScript** - Đổi tên sau đó
3. **JavaScript** (1996) - Đổi tên lần cuối, khoảng một năm sau khi phát hành, với hy vọng tận dụng sự phổ biến của cộng đồng Java (mặc dù JavaScript không có mối quan hệ nào với Java)

Netscape 2.0 được phát hành với sự hỗ trợ chính thức của JavaScript.

## **Các Phiên Bản JavaScript**

JavaScript, được phát minh bởi Brendan Eich, đạt được địa vị tiêu chuẩn ECMA vào năm 1997 và được đặt tên chính thức là **ECMAScript**.

Ngôn ngữ này đã phát triển qua nhiều phiên bản:

| Phiên bản        | Năm      | Đặc điểm nổi bật                                       |
| ---------------- | -------- | ------------------------------------------------------ |
| **ES1**          | 1997     | Phiên bản đầu tiên                                     |
| **ES2**          | 1998     | Cải tiến nhỏ                                           |
| **ES3**          | 1999     | Regular expressions, try/catch                         |
| **ES5**          | 2009     | Strict mode, JSON support, Array methods               |
| **ES6 (ES2015)** | 2015     | Arrow functions, classes, modules, promises, let/const |
| **ES2016+**      | 2016-nay | Cập nhật hàng năm với tính năng mới                    |

**ES6** được coi là bản cập nhật quan trọng nhất, mang đến nhiều thay đổi lớn giúp JavaScript trở nên hiện đại và mạnh mẽ hơn.

Các bản cập nhật này đã đóng vai trò quan trọng trong việc cải thiện và chuẩn hóa JavaScript, khiến nó trở nên được sử dụng rộng rãi và có giá trị trong lĩnh vực phát triển web không ngừng thay đổi.

## Tại Sao Học JavaScript?

1. **Universal Language** - Chạy trên browser, server (Node.js), mobile (React Native)
2. **Huge Ecosystem** - npm, frameworks, libraries vô số
3. **High Demand** - Skill được tìm kiếm nhất trong ngành IT
4. **Beginner Friendly** - Cú pháp dễ học, feedback ngay lập tức
