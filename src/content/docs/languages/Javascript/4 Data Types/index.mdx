## So sánh nhanh

| Đặc điểm      | Primitive       | Non-primitive (Object)       |
| ------------- | --------------- | ---------------------------- |
| **Bất biến?** | ✅ Immutable    | ❌ Mutable                   |
| **So sánh**   | Theo giá trị    | Theo tham chiếu              |
| **Copy**      | Copy giá trị    | Copy tham chiếu              |
| **typeof**    | Trả về tên kiểu | `"object"` hoặc `"function"` |

<Aside type="tip" title="Ghi nhớ">
	- **7 Primitive types**: `number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `symbol` - **Non-primitive**: Mọi thứ còn lại — Objects,
	Arrays, Functions, Date, Map, Set, …
</Aside>
