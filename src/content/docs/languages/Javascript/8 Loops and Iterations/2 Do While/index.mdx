## `do...while` là gì?

Câu lệnh `do...while` tạo ra một vòng lặp thực thi câu lệnh được chỉ định cho đến khi điều kiện kiểm tra trả về `false`. Điều kiện sẽ được đánh giá **sau khi** câu lệnh được thực thi, vì vậy câu lệnh sẽ luôn được chạy **ít nhất một lần**.

```js
do {
  // khối lệnh
} while (điều_kiện);
```

## Khác gì với `while`?

<Tabs>
  <TabItem label="while (kiểm tra trước)">
    ```js
    let i = 10;
    while (i < 5) {
      console.log(i); // ← KHÔNG BAO GIỜ chạy
      i++;
    }
    // Không có output — điều kiện sai ngay từ đầu
    ```
  </TabItem>
  <TabItem label="do...while (chạy trước)">
    ```js
    let i = 10;
    do {
      console.log(i); // ← CHẠY 1 LẦN: in ra 10
      i++;
    } while (i < 5);
    // Output: 10
    ```
  </TabItem>
</Tabs>

<Aside type="note" title="Điểm khác biệt duy nhất">
- `while`: kiểm tra **điều kiện trước** → nếu sai ngay → **không chạy lần nào**
- `do...while`: chạy **ít nhất 1 lần**, rồi mới kiểm tra điều kiện
</Aside>

## Ví dụ thực tế: Retry với giới hạn

```js
let attempts = 0;
let success = false;

do {
  attempts++;
  console.log(`Lần thử ${attempts}...`);

  // Giả lập: 30% xác suất thành công
  success = Math.random() < 0.3;

  if (success) {
    console.log("✅ Thành công!");
  } else if (attempts >= 5) {
    console.log("❌ Hết số lần thử.");
  }
} while (!success && attempts < 5);
```

<Aside type="tip" title="Ghi nhớ">
`do...while` = "**làm trước, hỏi sau**". Dùng khi bạn **chắc chắn** cần chạy khối lệnh ít nhất 1 lần trước khi kiểm tra điều kiện.
</Aside>
